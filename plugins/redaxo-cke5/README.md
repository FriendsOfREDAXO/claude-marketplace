# redaxo-cke5

Claude Code plugin for the [CKE5 addon](https://github.com/FriendsOfREDAXO/cke5) – the CKEditor 5 integration for REDAXO.

## Skills

| Skill | Activates when… |
|---|---|
| `cke5-style-add` | User wants to add a custom CKE5 style, mentions `rex_cke5_styles`, or needs editor/frontend CSS for a new style |

## Install

```bash
/plugin install redaxo-cke5@redaxo-marketplace
```
