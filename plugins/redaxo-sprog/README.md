# redaxo-sprog

Claude Code plugin for the [Sprog addon](https://github.com/FriendsOfREDAXO/sprog) – wildcard-based text management for REDAXO.

## Skills

| Skill | Activates when… |
|---|---|
| `sprog-overview` | User asks what Sprog is, wants to output wildcards in modules/templates, reads values from PHP, or works with Sprog for the first time |
| `sprog-add` | User wants to add Sprog wildcards, mentions `rex_sprog_wildcard`, or needs multi-language text setup |

## Install

```bash
/plugin install redaxo-sprog@redaxo-marketplace
```
